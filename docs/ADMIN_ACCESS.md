# مدیریت چندمدیره AVELORA

## راه‌اندازی اولیه

این نسخه به‌جای کلید مشترک برای ورود روزانه، برای هر مدیر حساب مستقل و نشست امن ایجاد می‌کند.

1. پیش از هر تغییر، از پایگاه داده نسخه پشتیبان بگیر.
2. پس از دریافت این شاخه، مهاجرت زیر را فقط روی پایگاه داده اصلی فروشگاه اجرا کن:

```bash
cd ~/Minimarkettiyam/backend
psql -d minimarkettiyam -v ON_ERROR_STOP=1 -f ../database/migrations/005_admin_rbac.sql
```

3. سرور را با روش فعلی خودت راه‌اندازی مجدد کن.
4. صفحه `/admin/` را باز کن. اگر هنوز حساب مالک ساخته نشده باشد، فرم راه‌اندازی یک‌باره نمایش داده می‌شود.
5. کلید فعلی `ADMIN_API_KEY` را فقط در همان فرم راه‌اندازی وارد کن و برای مالک یک نام کاربری و رمز عبور قوی با حداقل ۱۲ نویسه بساز.
6. پس از ساخت مالک، کلید مشترک دیگر برای ورود روزانه استفاده نمی‌شود. ورودهای بعدی فقط با نام کاربری و رمز شخصی انجام می‌شوند.

## ساخت مدیران دیگر

از صفحه «مدیران» حساب جدید بساز و فقط مجوزهای مورد نیاز را انتخاب کن. هر مدیر نام کاربری و رمز مستقل دارد. مالک می‌تواند دسترسی‌ها را تغییر دهد، رمز مدیر را بازنشانی کند یا حساب او را غیرفعال کند. با غیرفعال‌سازی یا تغییر رمز، نشست‌های قبلی آن مدیر باطل می‌شوند.

مجوزهای فعلی:
- محصولات: مشاهده، ثبت، ویرایش و بایگانی
- سفارش‌ها: مشاهده و تغییر وضعیت
- مشتریان: مشاهده
- تنظیمات: مشاهده و تغییر
- گزارش‌ها: مجوز آماده برای بخش گزارش‌های آتی
- سوابق فعالیت: مشاهده ورودها و تغییرات ثبت‌شده

مجوز تغییر، امکان مشاهده همان بخش را نیز فراهم می‌کند. هیچ مدیر فرعی نمی‌تواند حساب مدیر بسازد یا مجوز خودش را افزایش دهد.

## نشست و ثبت سوابق

- نشست مدیر با کوکی HttpOnly و SameSite=Strict نگهداری می‌شود و پس از ۲۴ ساعت منقضی می‌شود.
- خروج، نشست جاری را از پایگاه داده حذف می‌کند.
- تغییرات مدیریتی، ورود و خروج با حساب مدیر، مسیر، زمان، نتیجه درخواست و IP ثبت می‌شوند.
- غیرفعال‌کردن مدیر، همه نشست‌های فعال او را باطل می‌کند.
- حذف فیزیکی مدیر در پنل ارائه نشده؛ غیرفعال‌سازی برای حفظ سوابق فعالیت امن‌تر است.

## بررسی پس از نصب

```bash
cd ~/Minimarkettiyam/backend
npm run check
npm run test:zarinpal
npm run test:integration
```

مهاجرت را ابتدا روی پایگاه داده آزمایشی و پس از پشتیبان‌گیری روی پایگاه اصلی اجرا کن. هیچ کلید یا رمز عبوری را در پیام یا گزارش ترمینال برای کسی ارسال نکن.

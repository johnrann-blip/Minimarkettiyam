# اتصال درگاه زرین‌پال AVELORA

این تغییرات فقط زیرساخت اتصال را آماده می‌کند. پرداخت آنلاین به‌صورت پیش‌فرض خاموش است و هیچ اطلاعات پذیرنده یا بانکی در GitHub ذخیره نمی‌شود.

## حسابی که بعداً باید متصل شود

پس از انتشار سایت:
1. صاحب واقعی کسب‌وکار باید حساب پذیرندگی زرین‌پال را به نام خودش/شخص یا شرکت واجد شرایط بسازد و احراز هویت و درخواست درگاه را تکمیل کند.
2. حساب بانکی معرفی‌شده برای تسویه باید متعلق به همان صاحب پذیرندگی و مورد قبول زرین‌پال باشد؛ جزئیات و شرایط نهایی را پنل زرین‌پال تعیین می‌کند.
3. از پنل زرین‌پال، Merchant ID مربوط به درگاه را دریافت می‌کنیم.
4. Merchant ID فقط در متغیر محرمانه سرور قرار می‌گیرد، نه در frontend و نه در GitHub.

حساب GitHub، حساب میزبانی سایت و حساب بانکی سه موضوع جدا هستند. برای دریافت پول فروشگاه، حساب پذیرندگی زرین‌پال و حساب بانکی تسویه لازم است.

## متغیرهای محیطی سرور

برای آزمایش Sandbox، پس از انتشار یک نشانی HTTPS عمومی:
- ZARINPAL_ENABLED=true
- ZARINPAL_MODE=sandbox
- PUBLIC_BASE_URL=https://YOUR-DOMAIN

در Sandbox اگر Merchant ID تنظیم نشده باشد، کد از شناسه آزمایشی استفاده می‌کند. این شناسه برای دریافت پول واقعی نیست.

برای بهره‌برداری واقعی، فقط بعد از تأیید پذیرندگی:
- ZARINPAL_MODE=production
- ZARINPAL_MERCHANT_ID=... (محرمانه در تنظیمات سرور)
- ZARINPAL_ENABLED=true
- PUBLIC_BASE_URL=https://YOUR-DOMAIN

هرگز کلید یا شناسه محرمانه را در فایل‌های عمومی، پیام یا frontend قرار ندهید.

## مسیرها
- GET /api/payments/zarinpal/status: وضعیت آماده‌بودن پیکربندی
- POST /api/payments/zarinpal/request: ساخت درخواست پرداخت برای سفارش موجود؛ بدنه شامل order_code و phone
- GET /api/payments/zarinpal/callback: بازگشت از درگاه و تأیید سمت سرور

## واحد پول
قیمت‌های فروشگاه به تومان هستند. هنگام ارسال به API زرین‌پال، مبلغ با ضریب ۱۰ به ریال تبدیل می‌شود. مبلغ تأییدشده با مبلغ ذخیره‌شده سفارش مقایسه می‌شود.

## مهاجرت پایگاه داده
پس از دریافت تغییرات، قبل از اجرای سرور:
```bash
psql -d minimarkettiyam -f ../database/migrations/003_zarinpal_payments.sql
```
برای تست یکپارچه نیز مهاجرت را روی دیتابیس آزمایشی اجرا کنید:
```bash
psql -d minimarkettiyam_test -f ../database/migrations/003_zarinpal_payments.sql
```

تا زمان داشتن دامنه عمومی HTTPS و تنظیمات سرور، پرداخت آنلاین خاموش بماند. اجرای callback روی localhost برای پرداخت واقعی قابل استفاده نیست.

# ارزیابی اولیه میزبان AVELORA

این یک بررسی قابلیت‌هاست، نه تأیید خرید یا تضمین عملکرد.

## نامزد قابل بررسی: هاست‌ایران +Framework

صفحه رسمی +Framework اعلام می‌کند که سرویس قابلیت فعال‌سازی PostgreSQL، انتخاب نسخه‌های Node.js، دسترسی SSH/Terminal، SSL رایگان و پشتیبان‌گیری مستمر دارد:
https://www.hashe.me/host/framework-plus

این قابلیت‌ها با معماری AVELORA (Express + PostgreSQL) هم‌خوانی اولیه دارند؛ اما قبل از خرید باید پشتیبانی کتبی فروشنده برای موارد زیر گرفته شود:

1. اجرای دائمی Express با Node.js 22 یا نسخه سازگار پروژه و امکان اجرای `npm ci` / `npm start`.
2. اتصال PostgreSQL از Node.js به دیتابیس همان سرویس و محدودیت حجم/اتصالات.
3. ماندگاری فایل‌های `backend/uploads/` پس از restart، redeploy و تغییر نسخه Node.
4. اتصال دامنه اختصاصی و صدور/تمدید خودکار SSL برای دامنه اصلی و www.
5. زمان‌بندی، مدت نگهداری و هزینه restore بکاپ دیتابیس و فایل‌ها؛ بکاپ میزبان جای بکاپ مستقل ما را نمی‌گیرد.
6. امکان اجرای cron برای بکاپ خارج از سایت یا امکان اتصال به فضای ذخیره‌سازی S3-compatible.
7. قیمت نهایی ماهانه/سالانه، مالیات، هزینه تمدید و محدودیت منابع.

تا دریافت پاسخ و تأیید بودجه توسط مالک، هیچ خریدی انجام نشود.

## دامنه

دامنه پیشنهادی قبلی کاربر `avelora-shop.ir` بود، اما آزاد بودن فعلی آن از WHOIS رسمی در این بررسی تأیید نشد. موجود بودن باید در لحظه خرید از ثبت‌کننده/ایرنیک بررسی شود. ثبت دامنه .ir نیازمند شناسه ایرنیک متعلق به خود مالک است؛ از شناسه شخص ثالث استفاده نکنید.

## پس از تهیه سرویس

- DNS دامنه به IP/target میزبان متصل شود.
- گواهی HTTPS معتبر صادر شود.
- redirect از HTTP به HTTPS و host canonical تنظیم شود.
- `PUBLIC_BASE_URL` روی نشانی HTTPS نهایی تنظیم شود.
- cookieهای secure و callbackهای پرداخت در محیط واقعی آزمایش شوند.
- گواهی با ابزار SSL و تمدید خودکار پایش شود.

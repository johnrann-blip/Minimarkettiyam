## موانع مسدودکننده انتشار

### P0 — تشخیص IP پشت reverse proxy

- [ ] تعیین دقیق reverse proxy hop/subnetهای مورد اعتماد در میزبان
- [ ] تنظیم متغیر محیطی اجباری `TRUST_PROXY` در production
- [ ] استفاده از `TRUST_PROXY=1` فقط وقتی دقیقاً یک پروکسی مورد اعتماد وجود دارد
- [ ] اطمینان از اینکه پروکسی هدرهای `X-Forwarded-For` ارسالی کاربر را بازنویسی می‌کند
- [ ] بررسی جدا بودن Rate Limit مشتریان مختلف از پشت همان پروکسی
- [ ] تا زمان پیاده‌سازی rate-limit مشترک، اجرای فقط یک نمونه backend

کد اکنون تنظیم پروکسی را صریح و قابل پیکربندی می‌کند و آزمون یکپارچه برای تفکیک IP مشتریان از پشت پروکسی دارد. در production، نبود `TRUST_PROXY` مانع راه‌اندازی می‌شود. محدودکننده فعلی در حافظه هر پردازش است و با چند نمونه backend مشترک نیست.


### P0 — احراز مالکیت شماره موبایل و بازیابی رمز

- [ ] انتخاب سرویس‌دهنده پیامک و تهیه دسترسی امن آن
- [ ] افزودن OTP با انقضای کوتاه، محدودیت تعداد تلاش و محدودیت ارسال مجدد
- [ ] ثبت وضعیت تأیید شماره در حساب مشتری
- [ ] جلوگیری از فعال‌شدن تخفیف عضویت تا تأیید شماره
- [ ] طراحی بازیابی رمز با OTP و ابطال نشست‌های قبلی
- [ ] آزمون ثبت‌نام، ورود، OTP اشتباه/منقضی، ارسال مجدد و بازیابی رمز

وضعیت فعلی: عضویت با شماره و رمز عبور انجام می‌شود اما مالکیت شماره تأیید نمی‌شود؛ بازیابی امن رمز هم وجود ندارد. این نقص برای عرضه عمومی باید تعیین تکلیف شود.

### P0 — دامنه، میزبانی و HTTPS

- [ ] انتخاب و تهیه دامنه
- [ ] انتخاب میزبان سازگار با Node.js و PostgreSQL
- [ ] راه‌اندازی HTTPS معتبر و تمدید خودکار گواهی
- [ ] تنظیم `PUBLIC_BASE_URL` با نشانی HTTPS واقعی
- [ ] تنظیم `NODE_ENV=production`
- [ ] ساخت `DATABASE_URL` امن و `ADMIN_API_KEY` تصادفی حداقل ۳۲ بایت
- [ ] اطمینان از اینکه هیچ فایل `.env`، رمز، کلید یا اطلاعات بانکی وارد Git نشده است
- [ ] بررسی دسترسی فروشگاه و پنل از اینترنت موبایل و شبکه مستقل

وضعیت فعلی: دامنه و هاست هنوز تهیه نشده‌اند.

### P0 — ماندگاری تصاویر و پشتیبان‌گیری

- [ ] نگهداری `backend/uploads` روی فضای پایدار، نه دیسک موقت میزبان
- [ ] پشتیبان زمان‌بندی‌شده PostgreSQL
- [ ] پشتیبان فایل‌های تصاویر محصولات
- [ ] نگهداری نسخه پشتیبان خارج از میزبان اصلی
- [ ] آزمون بازیابی دیتابیس و تصاویر در محیط جداگانه
- [ ] تعیین دوره نگهداری و دسترسی محدود به نسخه‌های پشتیبان

هشدار: حذف یا بازنویسی پوشه محلی `backend/uploads/` ممنوع است؛ تصاویر واقعی محصولات در آن قرار دارند.

### P0 — مهاجرت پایگاه داده

- [ ] بررسی ساختار و شمارش داده‌ها پس از مهاجرت

وضعیت فعلی: مهاجرت‌های ۰۰۵ و ۰۰۶ در آزمون یکپارچه روی دیتابیس آزمایشی اجرا شده‌اند؛ دیتابیس اصلی نباید در این مرحله تغییر کند.

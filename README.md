# AVELORA Store — MVP foundation

فروشگاه چندمحصولی فارسی برای کیف، لوازم آرایشی و دسته‌های قابل‌افزایش.

## وضعیت این بسته
این نسخه، پایه اجرایی پروژه است: نمایش محصولات، جست‌وجو و فیلتر دسته، سبد خرید سمت مرورگر، ثبت سفارش با پرداخت کارت‌به‌کارت و پنل ساده مدیریت محصولات/سفارش‌ها.
این نسخه هنوز برای انتشار عمومی و دریافت پول آماده نیست؛ پیش از استفاده واقعی باید احراز هویت مدیر، HTTPS، بارگذاری امن رسید، محدودسازی سوءاستفاده، پشتیبان‌گیری و آزمون نهایی تکمیل شوند.

## نیازمندی‌ها
- Node.js 20 یا جدیدتر
- PostgreSQL 14 یا جدیدتر
- Termux یا Linux

## نصب در Termux
```bash
pkg update
pkg install nodejs-lts postgresql
cd ~/Minimarkettiyam/backend
npm install
```

پایگاه داده را بسازید و schema را اجرا کنید:
```bash
createdb minimarkettiyam
psql -d minimarkettiyam -f ../database/schema.sql
```

فایل تنظیمات:
```bash
cp .env.example .env
nano .env
```
مقادیر `DATABASE_URL` و `ADMIN_API_KEY` را با مقادیر واقعی و محرمانه تنظیم کنید. کلید مدیر را در اختیار مشتریان نگذارید.

اجرای محلی:
```bash
npm run start
```
سایت:
- فروشگاه: http://127.0.0.1:3000
- پنل مدیریت: http://127.0.0.1:3000/admin

## روش سفارش
1. مشتری محصولات را به سبد اضافه می‌کند.
2. نام، تلفن و نشانی را وارد می‌کند.
3. سفارش با وضعیت `awaiting_payment` ثبت می‌شود.
4. شماره کارت و نام صاحب حساب باید بعداً در تنظیمات امن سایت قرار گیرد؛ در این نسخه از نمایش اطلاعات بانکی ساختگی خودداری شده است.
5. مدیر پس از تطبیق واریز واقعی، وضعیت سفارش را از پنل تغییر می‌دهد.

## API اولیه
- `GET /api/health`
- `GET /api/products`
- `GET /api/categories`
- `POST /api/orders`
- `GET /api/admin/orders` (نیازمند `x-admin-key`)
- `PATCH /api/admin/orders/:id/status` (نیازمند `x-admin-key`)
- `POST /api/admin/products` (نیازمند `x-admin-key`)
- `PATCH /api/admin/products/:id` (نیازمند `x-admin-key`)
- `DELETE /api/admin/products/:id` (نیازمند `x-admin-key`)

## نکات پیش از بهره‌برداری
- کارت‌به‌کارت فقط با تأیید دستی مدیر انجام می‌شود؛ تصویر رسید، به‌تنهایی مدرک قطعی نیست.
- درگاه پرداخت آنلاین در این مرحله وجود ندارد.
- هزینه ارسال و سیاست مرجوعی هنوز باید توسط فروشگاه تعیین شود.
- تصاویر نمونه یا اطلاعات ساختگی محصول وارد نشده‌اند؛ محصولات واقعی را مدیر اضافه می‌کند.
- برای انتشار اینترنتی، دامنه، HTTPS، تنظیمات سرور و بررسی حقوقی/مالیاتی لازم است.
